# ArrowVortex Vision

## Ultimate Goal
ArrowVortex aims to be more than just a simfile editor; it is the foundation for a gamified crypto-economy centered around physical activity. By integrating "Proof of Dance" (PoD) mechanics, the application rewards users for their gameplay performance with **Bobcoin**, a privacy-focused, high-speed cryptocurrency.

## Core Concepts
- **Proof of Dance**: A consensus mechanism where mining is achieved through physical movement and accuracy in rhythm gameplay.
- **Privacy First**: Integration of RingCT and stealth addresses to ensure user anonymity within the Bobcoin ecosystem.
- **Accessible Creation**: Empowering the community with AI-driven tools (DDC) to generate high-quality charts for any audio, reducing the barrier to entry for content creators.
- **Cross-Platform**: A unified experience across Windows, Linux, and macOS.

## User Satisfaction
The project prioritizes a seamless, "one-click" generation experience. A user should be able to select any audio file (e.g., a psytrance set) and receive a complete set of perfectly synced charts for all difficulties automatically.
